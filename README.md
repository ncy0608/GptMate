# GptMate

<img src="Resources/GptMateIcon.png" width="128" alt="GptMate icon">

一个轻量的 macOS 菜单栏工具，用于查看 Codex 剩余额度、运行任务和任务结束提醒。

这是个人开发的非官方项目，与 OpenAI 无隶属关系。

## 功能

- 菜单栏显示运行任务数量与额度圆环。
- 根据剩余额度切换颜色：大于 30% 为绿色 `#28CD41`，大于 10% 且不超过 30% 为黄色 `#FFCC00`，不超过 10% 为红色 `#FF3B30`。
- 额度为 0% 时显示细红环，面板中的剩余百分比标红。
- 面板展示额度周期、剩余比例、重置时间，以及最多 5 个运行任务和可用的步骤摘要；任务按名称、状态、本轮时长三栏显示，无任务时只显示一行。
- 面板高度随内容自动收缩，Spark 额度默认折叠，关闭面板后恢复折叠；菜单栏不显示鼠标悬浮提示。
- macOS 版自动发现接口返回的所有额度分组，按名称展示通用和模型专属额度；每组独立显示主、次周期。内容较多时可滚动查看。
- macOS 版显示额度重置倒计时，额度与任务分别判断读取失败和过期：任务超过 30 秒、额度超过 5 分 30 秒未成功更新时，仅对应区域标记旧数据；连接断开时两部分均标记旧数据。
- macOS 版显示任务活动与本轮时长；有明确依据时展示思考、执行命令、修改文件、读取内容、搜索、整理上下文、等待确认或等待输入。等待处理的任务优先显示。
- macOS 任务约每 8 秒刷新；额度由事件触发更新，并每 5 分钟兜底刷新。打开面板、电脑唤醒及手动刷新时立即补刷额度和任务。
- macOS 未变化的任务日志复用解析结果；面板关闭时停止秒级计时，菜单栏圆环仅在额度或过期状态变化时重绘。
- 连接进程退出后尝试重连，支持手动刷新、重连和退出。
- 任务结束时发送系统通知；需要用户允许通知。macOS 版仅根据已观察任务的明确结束记录提醒，无法确认结果时显示“已结束”，并对重复事件去重。

## macOS 版

### 系统要求

- macOS 13 或更新版本。
- 本机安装并登录可用的 Codex 环境。应用通过本机 `codex app-server --stdio` 获取数据。
- 编译需要提供 Swift 编译器与 macOS SDK 的 Xcode Command Line Tools。

应用会检查 ChatGPT/Codex 应用包内的 CLI，以及 Homebrew、`~/.local/bin`、`~/.cargo/bin` 等常见安装位置。

### 从源码构建

在仓库根目录执行：

```bash
bash scripts/build.sh
```

分别生成两个单架构应用：Intel Mac 使用 `dist/x86_64/GptMate.app`；Apple Silicon（M 系列）Mac 使用 `dist/arm64/GptMate.app`。在“关于本机”中查看芯片或处理器类型，选择对应版本复制到自己的 Applications 文件夹后打开即可。

运行 macOS 状态与额度解析回归检查（使用合成数据，无需登录账号）：

```bash
bash scripts/test-mac-status.sh
```

创建分发压缩包及 SHA-256 校验文件：

```bash
bash scripts/package.sh
```

发布时提供 `GptMate-v0.3.0-macOS-Intel-x86_64.zip` 和 `GptMate-v0.3.0-macOS-AppleSilicon-arm64.zip` 两个下载包，分别对应 Intel 和 M 系列芯片。每个压缩包附带独立的 `.sha256` 校验文件。

构建产物使用本地 ad-hoc 签名，尚未完成 Apple Developer ID 签名和公证。下载的应用可能受到 macOS 安全验证限制；有疑虑时可检查源码并自行构建。本项目不提供关闭系统安全检查的脚本。

## 使用与隐私

启动后点击菜单栏圆环或任务文字查看面板。macOS 版优先读取完整的 `rateLimitsByLimitId`，兼容旧版 `rateLimits` 响应，不重复展示旧字段中的同一组额度。分组名称优先使用服务端的 `limitName`，缺失时使用类别标识；周期按实际分钟数显示，不按 Plus/Pro 套餐硬编码。

菜单栏圆环仍使用 Codex 通用额度的主窗口（仅次窗口可用时使用次窗口），不会自动切换到其他模型的最低剩余额度。没有通用分组时使用兼容默认分组。缺失的百分比不会当成 0%；没有重置时间时不推算日期。当前解析每个分组的 `primary` 和 `secondary` 周期窗口，不把信用余额或重置次数转换成额度百分比。

应用会读取 Codex 返回的本地会话日志路径，以辅助识别任务运行状态与当前活动。任务标题和可用的活动摘要可能显示在面板中，任务结束通知可能包含任务标题；请在分享截图时留意这些内容。

当前应用代码没有额外的分析上报或自建遥测服务。Codex CLI 自身的网络行为由其配置和服务决定。源码仓库与分发包不包含账号配置、Token、真实会话日志或启动台数据库。

仓库版由用户手动启动和退出，不会安装后台守护脚本。作者本机的自动启动配置不属于分发内容。

## 已知限制

- macOS 任务首次发现检查最近 20 个任务；已观察到的运行任务会继续检查其日志，面板最多展示 5 个。
- macOS 版任务结束结果取决于接口或日志提供的信息；缺少明确结果时仅提示“已结束”，未观察到运行过程的历史任务不会补发通知。
- 活动状态取自当前轮次的日志记录及可用的 `activeFlags`，不依据空闲时长或命令文本猜测。工具输出按调用 ID 配对；笼统的工具调用显示“执行工具”。其他进程中的 Codex 任务可能不返回等待标记，这时无法保证识别等待确认。
- 本轮时长从 `task_started` 的开始时间计算，包含等待时间；缺失开始时间时显示“时长未知”。数据过期时，时长停留在上次任务更新时间。
- 接口或本地会话日志格式变化可能影响兼容性。
- 暂未提供低额度通知、多账号管理与自动更新。
- 未发现额度数据时显示等待状态；macOS 版会明确标记失败后保留的旧数据。
