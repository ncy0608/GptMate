# GptMate v0.2.1 预览版

首个对外整理的预览版本，提供 macOS 菜单栏额度圆环、任务摘要和任务结束提醒。

- 额度圆环与进度条采用统一的红黄绿阈值。
- 提供 Intel（x86_64）和 Apple Silicon / M 系列（arm64）两个独立下载包，最低 macOS 13。
- 提供源码、可复现的构建步骤和分发压缩包校验值。

本版本使用本地 ad-hoc 签名，尚未完成 Apple 公证。已在开发机验证双架构编译和签名；Apple Silicon 实机运行尚未验证。

已知限制：任务仅检查最近 20 条，结束通知不能区分成功、失败或中止。请参阅 README。
