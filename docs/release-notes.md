# GptMate v0.3.0 预览版

本次更新完善 macOS 菜单栏额度与任务监控，压缩面板布局，并降低不必要的后台刷新。

## 更新内容

- 项目后续仅维护 macOS，移除 Windows 源码、自动构建流程及相关文档。

- 自动展示通用和模型专属额度；Spark 默认收起，每次关闭面板后重置为收起状态。
- 面板随内容自动缩放，任务按“名称、状态、本轮时长”三栏排列；无任务时只显示一行。
- 去除重复标题、更新时间行与菜单栏悬浮提示。
- 任务仍约每 8 秒检查，额度改为事件更新加每 5 分钟兜底；打开面板或唤醒电脑时补刷新。
- 未变化的日志复用解析结果，关闭面板后停止秒级计时，圆环仅在额度或过期状态变化时重画。
- 额度与任务分别判断读取失败和过期、独立恢复；连接断开时保留并标记旧数据。
- 根据当前轮次记录识别任务活动、运行时长与结束结果，并对结束提醒去重。

## 下载与安装

- Intel Mac：`GptMate-v0.3.0-macOS-Intel-x86_64.zip`
- Apple Silicon / M 系列：`GptMate-v0.3.0-macOS-AppleSilicon-arm64.zip`
- 最低 macOS 13，需要本机已安装并登录可用的 Codex 环境。
- 退出旧版 GptMate，解压后将 GptMate.app 替换到 Applications 文件夹，再重新打开。
- 每个 ZIP 附带 SHA-256 校验文件；应用包内附 MIT 许可证。

## 验证与限制

已验证双架构编译、ad-hoc 签名、状态/额度/日志回归检查及 Intel 开发机运行。Apple Silicon 实机运行与长期耗电尚未验证。

本版本仍为预览版，使用本地 ad-hoc 签名，尚未完成 Apple Developer ID 签名和公证，下载后可能受到 macOS 安全验证限制。

任务首次发现仅检查最近 20 个任务，面板最多显示 5 个；已观察到的运行任务会继续检查。其他 Codex 进程可能不返回等待标记，缺少明确结束结果时仅提示“已结束”。暂不提供自动更新、多账号管理和低额度通知。
